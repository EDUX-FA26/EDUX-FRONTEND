# EDUX Frontend Instructions

Before implementing UI:

1. Read `docs/UI_GUIDELINES.md`.
2. Apply the `ui-ux-pro-max` skill.
3. Preserve the existing React/Vite architecture.
4. Inspect existing components before creating new ones.
5. Do not invent backend APIs or data fields.

EDUX-specific design rules in `docs/UI_GUIDELINES.md`
override generic visual recommendations when they conflict.
